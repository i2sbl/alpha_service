# Images et photos du site Alpha Service

Ce dossier contient les images attendues par le site.

Fichiers attendus:
- `logo.png` : logo principal du site et image Open Graph
- `favicon.png` : favicon du navigateur
- `apple-touch-icon.png` : icône iOS / Apple

Emplacements recommandés pour les photos produit:
- `assets/images/produits/` : photos de vaisselle, mobilier, nappage, décoration
- `assets/images/hero/` : image de couverture pour la page d'accueil
- `assets/images/logo/` : variantes du logo (noir, blanc, icône)

Conseil : utilisez des noms explicites et sans espaces, par exemple :
- `assiette-blanche.png`
- `verre-champagne.png`
- `table-banqueting.png`
- `chemin-table-vert.png`

Les fichiers sont actuellement attendus par les balises meta et les liens de la page, mais la version actuelle du site utilise principalement des icônes vectorielles (FontAwesome) pour remplacer les photos temporaires.
